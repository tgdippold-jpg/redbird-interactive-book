# REDBIRD EPK Content Intake

This checklist separates confirmed project facts from material that still requires Tyler's approval. Do not publish or infer missing personal, legal, credit, contact, or media information.

- Project name: **REDBIRD**
- Public rollout begins: **September 2026**
- Lead release: **Self Love / Clark Gable**
- Self Love / Clark Gable is **one track**
- Taylor Swift Mashup Set: **single + B-side companion**

- Looping Pedal EP: **EP**, December 2026
- Full album arrival: **January 2027**
