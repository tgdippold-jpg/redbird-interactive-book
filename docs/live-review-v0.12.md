## Review rules

1. Do not add new feature categories until the live review is complete.
2. Treat broken links, confusing labels, unreadable mobile sections, and distracting interactions as must-fix items.
3. Treat placeholder copy, spacing polish, and release-page specificity as should-fix items.
4. Keep visible copy user-facing and avoid foregrounding GitHub, Netlify, JSON, or source-of-truth language in the public interface.
5. Preserve the book / zine / late-80s adventure-game feeling while improving usability.

## Next build direction after review

1. Convert review findings into a short fix list.

3. Replace placeholder release copy only where the related release package is mature enough.
